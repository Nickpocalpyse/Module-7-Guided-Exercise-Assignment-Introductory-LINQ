# Module-7-Guided-Exercise-Assignment-Introductory-LINQ
This is a modified project for the previous program. It has the same features, except for the added feature of being able to use queries and search for specific information.
You can choose the program in the combobox, the Name or ID in the text box, and the GPA in the Numeric Up/Down box.
There are many different buttons for filtering and sorting information.  Display Summary will display a summary of the info in the JSON.
The Files are stored in the Same location.  Module7JsonStudentRecords\Module7JsonStudentRecords\bin\Debug\net10.0-windows as students.json
A file with 10 entries is also in the repository for convenience in testing usage
